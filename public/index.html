Before you start

End-to-end encryption

Your messages and files are encrypted in this browser before they are sent. The server relays an encrypted handshake and never receives the keys, the file contents, the messages, or even the file names.

The link is the key

The secret lives after the # in the link, which browsers never send to a server. Anyone who has the link can join the gate, so share it the way you would share a password.

The two devices see each other's IP address

Warp Gate connects your devices directly. That is what keeps the server out of the data path, but it means each device learns the other's network address. Warp Gate does not make you anonymous. If hiding your address matters, use a VPN or Tor that you trust.

What this does not protect against

A compromised device or browser on either end, screenshots, or a recipient who chooses to save and forward what you sent. For something extremely sensitive, encrypt it yourself before sending it as well.

Lawful use

Warp Gate is intended for lawful use. You are responsible for what you send and for complying with the law where you are.
